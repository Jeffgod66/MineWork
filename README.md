# MineWork

MineWork 是注重隐私的本地工作台，由 Windowsland 改造而来，并以 eIsland 的“灵动岛展开”思路设计启动动画。

## 个人工作台

- 今日待办与完成度
- 月历与按日任务查看
- 日历行程与系统级提醒（关闭主页面后仍可提醒）
- 链接收藏夹、内容摘录与个人书架
- 本地 PDF、EPUB、MOBI、文档等文件导入书架
- 每日饮水记录与目标进度
- 每日三个问题复盘
- 30 条每日鼓励语，按日期自动轮换
- 按城市查询的实时天气与四日预报
- 每日实时热点资讯

## 桌面工具

- 快捷打开本地程序、文件与文件夹
- 倒计时和常用专注预设
- 中英日韩法德西自动翻译
- CPU、内存、磁盘和 GPU 状态
- MineRadio 精准媒体信息与控制，并兼容 Windows 系统媒体会话
- ChatGPT、Claude、DeepSeek 及常用邮箱，登录状态保存在本机持久会话
- 可调宽度的桌面灵动岛
- 灵动岛全区域滚轮切页；AI 页收起即安全卸载，避免透明窗口残影

## 账户与后台

左下角提供本机账户入口；首次使用时保持未登录，输入用户名即可创建本地显示名称，无需密码。可在账户面板中选择“关闭后驻留后台”；启用后，标题栏关闭按钮会隐藏主页面，灵动岛、日历提醒和托盘菜单继续运行。真正退出请使用系统托盘中的“退出”。

## 运行与数据

双击根目录下的 `MineWork.exe`。个人数据保存在 MineWork 的 Electron 本机用户数据目录中；AI 与邮箱 Cookie 使用 MineWork 独立的持久会话分区，不会与 Windowsland 混用。

天气数据来自 Open-Meteo，热点资讯聚合自 Google News RSS。MineWork 不收集个人数据。第三方许可见 `THIRD_PARTY_NOTICES.md`。
